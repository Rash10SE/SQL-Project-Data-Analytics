# 🚀 SQL Data Warehouse Analytics Project

📊 Project Overview

This project demonstrates an end-to-end SQL Data Analytics workflow using Microsoft SQL Server, focusing on exploring, analyzing, and interpreting sales data to generate meaningful business insights.

The project is built on a relational data warehouse following a Star Schema architecture, consisting of a sales fact table and customer and product dimension tables. It covers various analytical areas, including database exploration, business KPI calculations, sales trends, customer purchasing behavior, product performance, and revenue distribution.

Through a series of structured SQL scripts, different analytical techniques are applied to answer business-related questions. These include magnitude analysis, ranking analysis, change-over-time analysis, cumulative analysis, performance analysis, part-to-whole analysis, and data segmentation.

Furthermore, the project includes the development of two analytical views: Customer Report and Product Report. These reports consolidate important business metrics such as total sales, number of orders, purchasing frequency, average order value, customer lifespan, product performance, and revenue contribution.

Throughout the project, advanced SQL concepts and techniques are used, including:

* Joins and aggregations.
* Common Table Expressions (CTEs) and subqueries.
* Window functions and ranking functions.
* Date and time functions.
* Conditional statements using CASE WHEN.
* Data segmentation and analytical views.

The main objective is to demonstrate practical SQL expertise, strengthen analytical thinking, and showcase the ability to translate business requirements into meaningful insights that support data-driven decision-making.
